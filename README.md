<h1> Seção detalhada para os passos necessários para executar o código.</h1> 
<p> O código solicitará que você insira os valores de consumo dos últimos três meses Consumo do 3º último mês: Digite o valor em kWh e pressione Enter.

Consumo do 2º último mês: Digite o valor em kWh e pressione Enter.

Consumo do último mês: Digite o valor em kWh e pressione Enter.

Verificar os Resultados

O código calculará:

O valor final (após desconto e cobertura) para cada tipo de tarifa: Residencial, Comercial e Industrial.

A economia mensal para cada categoria.

A economia anual estimada para cada categoria.

Os resultados serão exibidos diretamente no terminal.

Exemplo de Entrada e Saída

Entradas Fornecidas pelo Usuário:

Consumo do 3º último mês: 8.500

Consumo do 2º último mês: 9.200

Consumo do último mês: 10.000

Saída no Terminal: </p>
